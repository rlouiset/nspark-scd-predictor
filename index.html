📋 Methodology

Model: XGBoost classifier (500 trees, max_depth=15, lr=0.01) trained on the NS-Park French real-world cohort (2,593 patients, 21,626 longitudinal segments). Predicts worsening of subjective cognitive decline (MDS-UPDRS Part I.1 ≥ 2 at follow-up, from baseline < 2).

Validation: AUC 0.80 on NS-Park held-out test set; AUC 0.73 on external PPMI cohort (n=1,467).

Feature contributions: The "What is driving this prediction?" chart displays exact SHAP (SHapley Additive exPlanations) values computed using the TreeSHAP algorithm (Lundberg et al., "From local explanations to global understanding with explainable AI for trees", Nature Machine Intelligence, 2020). TreeSHAP exploits the tree structure to compute Shapley values in polynomial time: each feature's contribution is its average marginal effect across all possible orderings of features, weighted by the training data distribution at each tree node. Unlike simpler perturbation methods, TreeSHAP guarantees additivity — contributions sum exactly to the difference between the prediction and the population baseline — as well as consistency and local accuracy. Features marked as N/A are excluded from the chart display. Computation runs entirely in-browser in JavaScript (~1 second per prediction for 500 trees).

Missing data: The XGBoost model natively handles missing values by learning optimal default split directions during training — when a feature is unknown, the model follows the path that was most common for missing values in the training data. This is a built-in capability of XGBoost (Chen & Guestrin, "XGBoost: A Scalable Tree Boosting System", KDD 2016).

Risk thresholds: Low risk (< 25%), Moderate (25–50%), and Elevated (> 50%) are indicative categories to aid interpretation. They are not clinically validated cut-offs.

Privacy: All computation runs entirely in your browser. No patient data is transmitted to any server.

Reference: Louiset et al., "Risk stratification of future subjective cognitive decline in Parkinson's disease using large-scale real-world routine clinical data" (2026).
