📋 Methodology

Model: XGBoost classifier (500 trees, max_depth=15, lr=0.01) trained on the NS-Park French real-world cohort (2,593 patients, 21,626 longitudinal segments). Predicts worsening of subjective cognitive decline (MDS-UPDRS Part I.1 ≥ 2 at follow-up, from baseline < 2).

Validation: AUC 0.80 on NS-Park held-out test set; AUC 0.73 on external PPMI cohort (n=1,467).

SHAP Interpretability: Instance-wise feature contributions computed using a marginal intervention approach — each feature is individually set to the population median while all others are held fixed, and the resulting change in log-odds quantifies its contribution.

Reference: Louiset et al., "Risk stratification of future subjective cognitive decline in Parkinson's disease using large-scale real-world routine clinical data" (2025).
